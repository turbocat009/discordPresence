# Privacy Policy

This app is very private

## Data Collection

This app collects data about your Discord's **Username**, **ID**, and **the name, type, description and image**. All this data is collected in order to be able to use the same preference for the app for the same Discord user in other computers, and to be able to use custom images.

## Data Sharing

All data collected on this app is completely private. I don't share any of it with anyone. The database is completely private (I'm the only one accessing it, and I'm not gonna share anything with anyone).

## Conclusion

I do actually care about digital privacy, more than anything else. For this reason this app is 100% private
