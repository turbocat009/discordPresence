# Discord Represence
An application to be able to modify your Discord Rich Presence live.

## Features:
- **Easy to use:** The program is very simple and intuitive
- **Cusomizable:** You can customize different thigs from your Discord Rich Presence
- **Open Source:** All what is involving this project has been open-sourced, so everyone can see the source.

## Building:
- Download the following dependences
  - SDL2, SDL2_image & SDL2_ttf
  - Discord Social SDK
  - libcurl
  - libtray
- Get the source & build it

## Things to know
- The app is in its first beta stage
- It may crash
- It is still on development
